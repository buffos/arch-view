# Interactive demo

<p class="small-note">This is a self-contained export. It does not run a new analysis and it does not need the Arch View server.</p>

<p><a class="VPButton medium brand" href="../demo/index.html">Open the interactive demo</a></p>

## What the demo shows

The demo contains a small, safe example with a few modules and dependency arrows. Use it to practice:

1. selecting a node;
2. reading the summary card;
3. opening inspection;
4. changing the layout;
5. looking at relationships.

The demo is generated from a sanitized fixture during the documentation build. It contains no private project source, tokens, or local file paths.

## What the demo cannot do

The static export cannot:

- analyze a new project;
- run a quality profile against your files;
- load source from the local filesystem;
- save a project configuration.

For those actions, follow the [Quick start](/guide/quick-start) and run the local server.
